# MarketOracle

> 本地运行的 A 股单股研究助手：**并行调研 → 多空对抗辩论 → CIO 裁决**，结论带证据编号、可回查公告原文页码。定位为研究辅助工具，不提供收益保证或交易指令。

MarketOracle 解决的是单股研究里「信息散、结论黑盒、模型容易编数」三个问题：把一次单股研究拆成可复现的若干步，每一步都落到证据上，最后输出带评级、置信度和多空分歧的结构化研报。

### 当前限制

- **数据覆盖**：公告 RAG 仅覆盖五粮液（000858.SZ）财报专题；其他标的目前只能做行情、新闻、风险问答。
- **扫描件**：扫描版 PDF 需要先 OCR，项目暂未内置。
- **原始文件**：仓库随附的是已处理数据（片段、页码、报告），不含原始 PDF。
- **运行环境**：依赖 `hello_agents` 环境与可用的模型服务，暂未提供独立依赖锁文件。
- **新闻 / 风险**：只覆盖数据源可检索范围，不代表公司完整披露。

## 核心能力

### 1. 有向研究流水线

一次研究固定走「三路并行调研 → 多空对抗辩论 → CIO 裁决 → Critic 核查」四步，每步的输入输出都是结构化对象（`ResearchBriefs`、`DebateTranscript`、`FinalResearchReport`），便于单测与回放。

### 2. 动态多空辩论

多头与空头围绕证据逐轮发言，先补证再公开发言；一整轮结束后由模型判断「是否有待回应反驳、是否会影响结论、下一轮能否推进」，三项齐备才续辩，最多 3 轮。到点即停，保留已生成实录，未完成发言不计入完整轮数。

### 3. 可审计的结论

所有工具取数统一分配 `EV_XXX` 证据编号并入库复用；研究员与辩手发言必须引用编号，程序用正则实时拦截未登记 / 伪造编号。CIO 只允许引用白名单内的证据，Critic 再核对报告里的数值、引用与风控完整性，未通过触发一次定向修订。

### 4. 高精度财报 RAG

用 `pdfplumber` 按坐标解析财报表格，校验单位、单季 / 累计口径、跨页续表与更正版本；按研究基准日隔离可见版本（防未来函数）。检索分两路：「结构化精确查数」（不依赖向量）与「Chroma 向量正文检索」，命中片段带原文页码，可回查论据出处。

### 5. 工程兜底

行情源东方财富失败自动切腾讯；辩论与工具调用设时间预算（研究 175s，预留 35s 给裁决）；向量服务故障只影响正文检索，不阻塞查数与行情；模拟数据模式可离线跑通全流程。

## 快速开始

### 环境

后端需要能导入 `hello_agents`（含 `HelloAgentsLLM`、`hello_agents.core.budget`）的 Python 环境，以及 `python-dotenv`、`pandas`；真实行情与资讯工具还需 `akshare`。仓库暂无独立依赖锁文件，已有 HelloAgents 环境请优先复用。

### 配置

在仓库根目录创建 `.env`，按自己的模型服务填写，切勿提交真实密钥：

```dotenv
MARKETORACLE_MODEL=deepseek-chat
MARKETORACLE_MODEL_KEY=<你的模型密钥>
MARKETORACLE_MODEL_URL=<你的模型服务基础地址>
```

公告正文检索另需 `DASHSCOPE_API_KEY` 与 `MARKETORACLE_EMBEDDING_URL`，且嵌入模型应与已建索引匹配。

### 命令行

```sh
python -m backend.cli --symbol 000858.SZ --as-of 2026-05-01 --mock-data
```

进入后可输入「这只股票有哪些风险？」继续追问，或输入 `/研报 风险与分歧` 生成研报。`/专业` 和 `/小白` 切换回答风格，`exit` 退出。`--mock-data` 模拟的是行情、资讯等资料，**不是离线模型**；去掉才会使用真实数据源。

### Web 界面

1. 启动后端：`python -m backend.web`。健康检查 `GET http://127.0.0.1:8765/api/health` 正常返回 `204`。
2. 另开终端进入 `frontend`，运行 `npm ci` 和 `npm run dev`。
3. 打开 Vite 打印的本地地址。前端通过 `/api` 代理请求后端；只启动前端不能完成研究问答。

## 测试

```sh
python -B -m unittest discover -s backend/tests -v
```

覆盖范围包括：行情主备源切换、时间窗口与异常；问答证据复用与流式返回；辩论动态轮数、超时中断与迟到发言屏蔽；公告解析、证据校验、版本隔离与回查页码。

## 数据说明

`backend/data/公告索引.csv` 是公告清单；`backend/data/rag/` 包含提取的页面、证据片段、处理报告及五粮液专题的 Chroma 向量索引。随仓库提供的是已处理数据，**不含原始 PDF**。查阅片段不用重新下载 PDF；核对原文或重新提取页面需准备相应源文件。
